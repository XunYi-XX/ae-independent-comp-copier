# 独立合成复制器

目标：让用户复制已有 AE 合成后，修改文字、嵌套合成、控制器和替换图片不会影响原合成或另一份副本。使用 AE 原生 ExtendScript / ScriptUI，单个 JSX 可运行及停靠，不增加网络、账户或构建依赖。

选择 ScriptUI，而非需要调试签名配置的 CEP / UXP 扩展或原生 C++ 效果插件。此任务操作工程项目结构，不需要逐像素渲染效果；原生脚本 API 可完成依赖复制和表达式改写。

数据流：选中源合成 → 预扫描嵌套图层及静态表达式引用 → 验证目标唯一性与素材支持范围 → 为每份副本建立独立映射 → 在原合成各自所在的目录中复制 → 重连素材和嵌套合成 → 从原表达式文本精确改写引用 → 检查结构和表达式 → 在面板列出新主合成名称。

表达式扫描器跳过注释、普通字符串和正则文本，只改 comp / footage 直接调用内的名字字面量。原图层名不变；内部图层索引、父级、遮罩由 duplicate 保留。对动态代码、重名目标、基本属性覆盖和暂未实现的导入类型，报告具体位置并在修改工程前停止。

v1.0.1 默认复用 AE 素材项目及其磁盘媒体，只新增合成。勾选独立复制素材时，才为各份副本新建素材项目及专用目录。每份副本使用单独的合成映射，同一份内部重复使用的嵌套合成只复制一次。

主合成和嵌套副本各自与原件同目录。主合成使用自定义名称及批量序号，嵌套合成使用新主合成名称作前缀，发生重名时自动追加后缀。保留复制前的项目面板选择，避免通过选中新副本展开文件夹。

失败处理：所有新项目记入本次事务；异常后逆序移除，恢复项目选择。原工程不保存、不关闭；原合成不写入。整个复制操作是一个 Undo Group。成功后的工程由用户保存。

验证：Node 中检查词法改写边界；AE 中用临时合成验证跨合成表达式、文字修改、素材替换、多份副本、重名处理、帧动画、父级、锁定图层、遮罩和失败回滚。原用户工程保持打开且不保存，临时测试项目清理。
